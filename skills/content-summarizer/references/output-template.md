# Template de Output — Content Summarizer

Sempre responder neste formato. Adaptar idioma para PT-BR. Nao pular secoes.

```
TL;DR
(2-3 frases objetivas do que e o conteudo e por que importa)

Pontos-chave
- (3-7 pontos mais relevantes)
- (ser especifico — dados, nomes, metodos, resultados)

Insights para seus projetos
- [Projeto 1] como se aplica
- [Projeto 2] como se aplica
- [Conhecimento Geral] aprendizado que nao se encaixa em projeto especifico
(incluir apenas projetos que se aplicam — nao forcar)

Hot take
(1-2 frases com opiniao sobre por que isso importa pro usuario. Direto e genuino, nao generico. Se o conteudo e mediano, dizer isso.)

Quotables
- "frase, dado ou estatistica impactante pronta pra usar em post"
- (1-3 trechos que funcionam como gancho para posts, palestras ou artigos)
- (se nao tem quotable bom: "Sem quotables de impacto neste conteudo")

Pra aprofundar
- (1-3 temas, termos para pesquisar ou fontes relacionadas)

Ideias de conteudo
- (1-3 sugestoes concretas com formato: "Post LinkedIn sobre X comparando Y com Z")
- (especificar formato: post LinkedIn, thread Twitter, artigo, video curto, newsletter)

Categoria: [AI/Tech/Negocios/Carreira/Marketing] | Nivel: [Basico/Intermediario/Avancado/Especialista]
```

## Regras

- Sempre PT-BR na saida, mesmo que conteudo original seja ingles
- Insights devem ser especificos — dizer exatamente COMO e PRA QUE, nao "pode ser util"
- Quotables devem ter dados concretos ou frases provocativas
- Ideias de conteudo devem ser acionaveis — "Post LinkedIn sobre X comparando Y com Z" e bom, "fazer um post sobre isso" e ruim
- Hot take genuino — nao inflar tudo como revolucionario
- Sem tabelas markdown (Telegram nao renderiza) — usar listas
